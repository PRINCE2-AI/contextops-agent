# Paper Notes

## AdaCoM

Inspires the external context manager that prunes stale context while preserving constraints and progress.

## MRAgent

Inspires active memory reconstruction instead of static top-k retrieval.

## Plans Don't Persist

Inspires explicit plan and constraint persistence outside the model context.

## ToolPrivacyBench

Inspires the privacy firewall and leak-count metric for tool payloads.

## AgenticSTS / ContextBudget

Inspires bounded-context evaluation, typed state, and token-budget-aware prompt assembly.

## What V1 Does Not Claim

- It is not a trained AdaCoM reproduction.
- It does not claim benchmark SOTA.
- It is a practical portfolio implementation of the research ideas.
