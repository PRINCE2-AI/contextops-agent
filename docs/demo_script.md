# Demo Script

1. Run `python demo.py`.
2. Show selected memories, context compression ratio, and token estimate.
3. Show that private email/API-key-like text is caught by the privacy firewall.
4. Show evaluation metrics: task success, plan retention, memory precision, privacy score.
5. Open the Streamlit dashboard with `streamlit run app/ui.py`.

Short pitch:

> I built a context engineering layer for long-horizon agents. It prevents agent amnesia, compresses stale history, reconstructs relevant memory, blocks privacy leakage to tools, and evaluates the agent context pipeline with measurable scores.
